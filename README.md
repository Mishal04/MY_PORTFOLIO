# ⚙️ Getting Started

Clone the repository

```bash
git clone https://github.com/Mishal04/MY_PORTFOLIO.git
```

Go to project folder

```bash
cd MY_PORTFOLIO
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```
